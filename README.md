# Studio37 Management Web App

Internal web application for managing music studio operations: bookings, flexible pricing, operator fees/commissions, payments, bookkeeping, users, permissions, and studio configuration.

## Planned stack

- React + Vite
- JavaScript / JSX
- Tailwind CSS + project CSS
- Firebase Authentication
- Cloud Firestore
- Firebase Hosting (`.web.app`)
- Firebase Spark Plan first
